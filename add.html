Share your game

Two ways to get a game onto UsForge. Neither needs a GitHub account.

1 · Send it to Taurus

Send your game however is easiest — a .zip of its folder, an HTML file, or a Claude artifact link — with its name and a one-line description. Taurus puts it up.

2 · Upload it yourself (members)

If you have a UsForge account, go to Upload, sign in, pick your game’s .zip (or folder, or HTML file), and press Upload. It’s live in about a minute, and you can update or remove your own games there any time.

Want an account? On the Upload page, use “Make your password code” and send the code to Taurus. You never have to tell anyone your password.

Getting your game as files

A game needs an index.html (plus any other files it uses). If your game is a Claude artifact, ask Claude in that chat: “give me this game as an HTML file I can download.” A link also works — the card then opens it in a new tab.

Game made of several files or folders? Zip it into one file: on a Mac, right-click the game’s folder → Compress; on Windows, right-click → Send to → Compressed (zipped) folder. Send or upload that .zip — UsForge unpacks it by itself.

Nice extras: a screenshot named cover.png in the folder becomes the game’s card picture.

House rules

  1. Only upload and change your own games.
  2. First names or nicknames only — no last names, photos, schools or addresses.
  3. Nothing mean about real people.
  4. If you want a game taken down, it comes down. No arguing.
