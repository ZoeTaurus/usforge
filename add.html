Add your game

Takes about two minutes, all in the browser. You need to be a member of the UsForge project on GitHub — ask whoever runs it to invite you.

1 · Get your game as files

Your game needs an index.html (plus any other files it uses). If your game is a Claude artifact link, ask Claude in that chat: “give me this game as an HTML file I can download.”

Can’t get files? You can still list it: skip the HTML and put a "url" in step 2 instead — the card will open your link in a new tab.

2 · Make a folder with a game.json

Name the folder with lowercase letters and dashes, like potato-dash. Put your game files in it, plus a file called game.json:

{
  "title": "Potato Dash",
  "author": "potato",
  "blurb": "Dodge the forks. One sentence is plenty."
}

Optional extras: a screenshot named cover.png (wide, like 16:10) · "pixel": true if it’s pixel art · "url": "https://…" for link-only games.

3 · Upload it

  1. Open the UsForge project on GitHub and go into the games folder.
  2. Click Add file → Upload files.
  3. Drag your whole game folder onto the page.
  4. Scroll down and click Commit changes.

That’s it. In about a minute your game shows up on the site — the list builds itself. (To change your game later, upload the new files into the same folder.)

House rules

  1. Only change your own games’ folders.
  2. First names or nicknames only — no last names, photos, schools or addresses.
  3. Nothing mean about real people.
  4. If you want a game taken down, it comes down. No arguing.
